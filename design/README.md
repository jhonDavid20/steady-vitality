# Entregables de Claude Design

Estos archivos son los artefactos interactivos generados por Claude Design el 2026-09-10. Ábrelos en un navegador desde esta carpeta; los tres dependen de `support.js`.

- `Sistema de Diseño.dc.html`: tokens, tipografía, componentes, estados y voz.
- `Landing - direcciones.dc.html`: las tres direcciones de landing; la dirección elegida es **1c**, evaluación como hero.
- `Mapa y flujos.dc.html`: navegación por rol y flujos prioritarios.

El alcance y la correspondencia con el código están en [`../CLAUDE_DESIGN_BRIEF.md`](../CLAUDE_DESIGN_BRIEF.md). Antes de implementar una pantalla, comprobar su endpoint, permiso de rol y estados de vacío/error en ese brief.
